💡 How to Add New System Audits (Zero-Code Dynamic Discovery) ▼

Option 1: Drop a script into scripts/

Place any executable Python script named audit_<name>.py in the scripts/ directory. DevCore's Discovery Engine automatically parses its module docstring via AST for title/summary and catalogs it immediately. If the script supports --json, its structured scorecard will automatically render in the dashboard.

Option 2: Register in core/audits_manifest.json

Add an entry into core/audits_manifest.json to declare arbitrary shell, bash, or python commands with custom categories without modifying any core engine code.
