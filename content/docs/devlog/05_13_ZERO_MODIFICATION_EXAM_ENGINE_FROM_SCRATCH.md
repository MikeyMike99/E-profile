# Chapter 05_13: Zero-Modification Exam Engine From Scratch

A step-by-step guide to writing the schema normalization engine (`format_exam.py`) line by line from a completely blank text editor window.

---

## What We Are Building & Beginner Safety Rules

We are creating `format_exam.py`—the server-side engine that transforms raw, messy JSON generated by AI models into clean, structured payloads that feed directly into our immutable frontend web templates.

### Beginner Safety Directives
1. **Never Touch the HTML/JS Templates**: All dynamic questions, choices, and timers are injected via JSON. We never modify `exam_application.html`.
2. **Convert Text Answers to Numeric Indices**: Frontend templates expect `correct_index: 0` (integer), not `"correct_answer": "Option A"` (string).
3. **Handle Missing Fields Gracefully**: If an AI fails to generate an explanation or puts questions in the wrong format, the script must provide sensible defaults instead of crashing.

### Block 2: Multiple Choice & Multi-Select Normalization (Lines 16–42)

Add the question loop and choice transformation logic:

```python
    new_questions = []
    for q in data.get("questions", []):
        # 1. Normalize question prompt key
        if "question" in q:
            q["text"] = q.pop("question")
            
        q_type = q.get("type", "multiple_choice")
        
        # 2. Transform Single-Choice Questions
        if q_type == "multiple_choice":
            if "correct_answer" in q and "options" in q:
                try:
                    q["correct_index"] = q["options"].index(q["correct_answer"])
                    del q["correct_answer"]
                except ValueError:
                    q["correct_index"] = 0
            new_questions.append(q)

        # 3. Transform Multi-Select Questions
        elif q_type == "multi_select":
            if "correct_answers" in q and "options" in q:
                indices = []
                for ans in q["correct_answers"]:
                    try:
                        indices.append(q["options"].index(ans))
                    except ValueError:
                        pass
                q["correct_indices"] = indices
                del q["correct_answers"]
            new_questions.append(q)
```

- **Lines 18–20**: If the AI called the question field `"question"`, renames it to `"text"`.
- **Lines 25–31**: Looks up where the correct answer text is in the options list (e.g., `["Apple", "Banana"].index("Banana")` -> `1`), and deletes the raw answer string.
- **Lines 35–42**: Converts lists of multiple correct strings into clean numerical arrays (e.g., `[0, 2]`).

## Complete Finished File Listing

```python
import json
import sys
import os

def format_exam_payload(json_path: str):
    if not os.path.exists(json_path):
        print(f"Error: File '{json_path}' not found.")
        sys.exit(1)

    with open(json_path, "r", encoding="utf-8") as f:
        data = json.load(f)

    new_questions = []
    for q in data.get("questions", []):
        if "question" in q:
            q["text"] = q.pop("question")
            
        q_type = q.get("type", "multiple_choice")
        
        if q_type == "multiple_choice":
            if "correct_answer" in q and "options" in q:
                try:
                    q["correct_index"] = q["options"].index(q["correct_answer"])
                    del q["correct_answer"]
                except ValueError:
                    q["correct_index"] = 0
            new_questions.append(q)

        elif q_type == "multi_select":
            if "correct_answers" in q and "options" in q:
                indices = []
                for ans in q["correct_answers"]:
                    try:
                        indices.append(q["options"].index(ans))
                    except ValueError:
                        pass
                q["correct_indices"] = indices
                del q["correct_answers"]
            new_questions.append(q)

        elif q_type == "dropdown_blank":
            if "blanks" in q:
                blanks = q.pop("blanks")
                text = q["text"]
                if isinstance(blanks, dict):
                    for b_name, b_data in blanks.items():
                        target = b_name if b_name.startswith("[") else f"[{b_name}]"
                        text = text.replace(target, "[BLANK]")
                        new_questions.append({
                            "type": "dropdown_blank",
                            "text": text,
                            "options": b_data.get("options", []),
                            "correct_text": b_data.get("correct_answer", ""),
                            "explanation": q.get("explanation", "")
                        })

    data["questions"] = new_questions
    with open(json_path, "w", encoding="utf-8") as f:
        json.dump(data, f, indent=2)
    print(f"Successfully normalized {len(new_questions)} questions in {json_path}")

if __name__ == "__main__":
    if len(sys.argv) > 1:
        format_exam_payload(sys.argv[1])
    else:
        print("Usage: python format_exam.py <path_to_json>")
```

## Beginner Coder Q&A

### Why do we delete `correct_answer` with `del`?
Deleting the text answer field ensures that students inspecting the raw browser developer tools cannot simply look at the JSON object to see the answer string!

### What happens if an answer string isn't in the options list?
The `except ValueError:` block catches the error and assigns index `0`, preventing the whole program from crashing.
