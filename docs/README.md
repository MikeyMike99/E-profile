# E-Profile Documentation & Content Source

Master documentation is version-controlled on GitHub in the **Central Documentation Vault**:
🔗 **GitHub Repository**: [https://github.com/MikeyMike99/Central_Docs/tree/main/projects/eprofile](https://github.com/MikeyMike99/Central_Docs/tree/main/projects/eprofile)

The web portal displays documents from `content/docs/`, which is automatically generated and synchronized from `Central_Docs` via:
```bash
python3 ../Central_Docs/scripts/sync_to_eprofile.py
```
